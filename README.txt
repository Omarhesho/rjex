# RJEX

نسخة بسيطة من موقع RJEX: منيو + سلة + صفحة تأكيد الطلب + تحديد الموقع + إرسال الطلب إلى الإيميل.

## قبل التشغيل

افتح `script.js` وابحث عن:

`const ORDER_EMAIL = "PUT_YOUR_EMAIL_HERE@example.com";`

واستبدلها بإيميل صاحب RJEX.

## إرسال الإيميل

المشروع يستخدم FormSubmit بدل Backend/Database حتى يفضل بسيطًا.
في أول إرسال قد يطلب FormSubmit تأكيد/تفعيل البريد.

## تحديد الموقع

زر تحديد الموقع يستخدم Geolocation API في المتصفح.
على الاستضافة الحقيقية يجب تشغيل الموقع عبر HTTPS حتى يعمل تحديد الموقع بشكل طبيعي.

## التواصل

عدّل النص الموجود في Footer داخل `index.html` وضع أرقام الهاتف/واتساب الحقيقية.

## الصور

كل صور المنتجات موجودة داخل `assets/` ومربوطة بالفعل بالمنتج الصحيح.
